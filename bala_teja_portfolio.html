Intrusion Detection System for IoT Devices

Built on a Jetson Orin Nano, this system watches traffic across a network of connected IoT devices and flags intrusion patterns in real time. As more of daily life runs through connected devices, the same convenience opens new attack surfaces — this project aims to close that gap by alerting users the moment suspicious activity is detected, rather than after the damage is done.

Healthcare AI Prototype

HealthGuide AI — Patient Triage & Advisory Assistant

A chat-based assistant designed for a hospital's patient-facing side. Patients describe symptoms in plain language and get triage-style guidance — not a diagnosis, but a clear next step: what to watch for, when to see a doctor, and how urgent it might be. Built-in quick-symptom shortcuts speed up common cases, a doctor directory and appointment scheduler let patients book or cancel visits without calling the front desk, and a country-aware emergency directory surfaces the right number immediately if symptoms sound serious. A persistent medical disclaimer keeps the tool honest about its limits, and it can run fully offline in a local demo mode or connect to a live AI model for richer conversations.
